# EK VILLAIN — PRIYANSHU
## Full Cinematic Redesign (2026)

Advanced portfolio redesign with powerful animation effects.

### Features
- **Cinematic Preloader** — Film countdown + progress ring + grain
- **Lenis Smooth Scroll** — Buttery inertia scrolling
- **GSAP + ScrollTrigger** — Reveal animations, counters, scene pinning
- **Three.js Particle System** — Interactive hero background
- **Custom Magnetic Cursor** — Dot + ring with hover states
- **Villain Mode** — Toggle dark intensity (press `V`)
- **Keyboard Navigation** — ↑↓ or J/K to move between scenes
- **Project Filtering** — AI / Data / Full Stack
- **Responsive** — Mobile optimized
- **Magnetic Buttons** — Subtle pull effect on hover

### Tech Stack
- HTML5 + CSS3 (Custom Properties)
- Vanilla JavaScript
- GSAP 3.12 (ScrollTrigger, ScrollToPlugin)
- Lenis (smooth scroll)
- Three.js r128 (particles)

### How to Run
1. Extract the zip
2. Open `index.html` in a modern browser  
   **OR** serve with any static server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
3. CDN libraries require internet connection on first load.

### Keyboard Shortcuts
| Key | Action              |
|-----|---------------------|
| ↑ / K | Previous scene    |
| ↓ / J | Next scene        |
| V     | Toggle Villain Mode |
