## Run locally

You can open `index.html` directly, but a local server is better because the GitHub API is fetched from JavaScript.

### Option 1 — VS Code
Use Live Server and open `index.html`.

### Option 2 — Python
```bash
python -m http.server 5500
```
Then open:
`http://localhost:5500`

## Deploy on GitHub Pages

1. Create a new repository, for example:
   `ek-villain-priyanshu`
2. Upload all files and folders.
3. Go to **Settings → Pages**.
4. Source: **Deploy from a branch**
5. Branch: `main` / root.
6. Save.
7. GitHub will provide the live URL.

## Notes

The project uses public CDN versions of Three.js, GSAP and Lenis. An internet connection is required for those libraries and for the live GitHub repository vault.

The repository vault is designed to keep the site current: it requests the public repositories of `priyanshu18611` at runtime. If the GitHub API is unavailable, the JavaScript includes a curated fallback list of known projects.
