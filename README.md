## ✦ Portfolio Concept

**EK VILLAIN — PRIYANSHU** combines three visual directions into one original portfolio experience:

- **Cinematic 3D presentation** — dark interface, depth, perspective, motion and dramatic visual hierarchy.
- **Editorial portfolio design** — oversized typography, clean spacing and structured information presentation.
- **Case-study storytelling** — project details organised around goals, approaches, technology and outcomes.

The goal is not to copy the supplied references, but to translate their presentation language into an original personal portfolio.

## ⚙️ Run Locally

This is a static portfolio and can be opened directly in a browser.

### Option 1 — Direct

Open:

```text
index.html
```

### Option 2 — VS Code

Use **Live Server** and open the generated local URL.

### Option 3 — GitHub Pages

1. Upload the project files to a GitHub repository.
2. Keep `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Select the deployment branch and root folder.
5. Save and open the generated GitHub Pages URL.

---

## 🔄 Updating an Existing Portfolio Repository

If replacing an older version:

**Replace:**

```text
index.html
style.css
script.js
README.md
```

**Keep:**

```text
assets/
```

Do not create a nested `assets/assets` folder. The expected structure is exactly:

```text
assets/images/
assets/resume/
```
