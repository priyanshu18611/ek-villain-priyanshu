## Creative direction

A cinematic dark presentation, cream editorial spreads, oversized
typography, perspective device mockups, project archives and
case-study storytelling — built as an original portfolio system, not a
copy of any reference site.

**Visual rhythm**

```
BLACK → CREAM → BLACK → CREAM → BLACK → CREAM → BLACK → BLACK → BLACK
```

Each section behaves like a new frame in a digital design magazine.

## Feature highlights

The full, dated changelog of every feature lives in
[`FEATURES-ADDED.md`](FEATURES-ADDED.md). The headline pieces:

| Category | What it does |
|---|---|
| 🎬 **Cinematic intro** | A real 5‑4‑3‑2‑1 film-leader countdown plays before the hero reveals — skipped instantly under reduced motion. |
| 🕸️ **Interactive particle network** | A lightweight, dependency-free canvas draws a constellation behind the hero that reacts to the cursor and pauses off-screen. |
| 🔤 **Text-scramble headline** | The hero title decodes out of scrambled characters the moment it appears. |
| 🎞️ **Cinematic horizontal archive** | On desktop, the project archive pins and scrolls sideways like a gallery reel; falls back to a normal grid on mobile. |
| 🧩 **Signature scrollytelling case study** | The CareerPilot AI case study pins in place and assembles itself — node by node, with connector lines drawing live — as you scroll. |
| 🎯 **Role-aware lens switcher** | Toggle "Software Engineer / Data Analyst / Full Stack Dev" to re-emphasize the matching skills and projects instantly. |
| 📊 **Live BI dashboard demo** | A working Power BI/Tableau-style dashboard (Chart.js, lazy-loaded) with KPI cards and a region filter. |
| ⌘ **Command palette** | Press `Ctrl`/`Cmd` + `K` to jump to any scene, project, or action — Linear/Vercel style. |
| 🐙 **Live GitHub data** | Real public repo/follower counts and a "latest on GitHub" feed, fetched from the GitHub API at load time. |
| 😈 **Villain Mode** | A glitch-and-scanline easter egg — toggle it from the nav, the `V` key, 5 clicks on the logo, or the Konami code. |
| ♿ **Accessible by default** | Skip link, ARIA roles, focus-trapped dialogs, real form labels, `prefers-reduced-motion` respected throughout. |
| ⚡ **Optimized for real visitors** | Deferred scripts, lazy-loaded charts, and animations that pause when the tab is in the background. |

## Accessibility

- Skip-to-content link for keyboard users
- ARIA roles/labels on every interactive control; decorative elements
  (canvas, cursor, grain) marked `aria-hidden`
- Real, screen-reader-visible `<label>`s on all form fields
- Focus is trapped and restored correctly for every dialog (project
  modal, command palette, resume viewer); `Esc` closes all of them
- Every animation respects `prefers-reduced-motion`

## SEO &amp; performance

- Open Graph + Twitter Card tags for clean link previews on
  LinkedIn/WhatsApp/X
- `Person` structured data (JSON-LD) for search engines
- Scripts load with `defer`; Chart.js is fetched only when the Data Lab
  section is actually scrolled into view
- `preconnect`/`dns-prefetch` for the font and API origins in use
- Animations (particles, marquee, Villain Mode pulse) pause automatically
  when the browser tab is in the background

> **Before going live:** swap the `og:image`/`twitter:image` for a
> dedicated 1200×630 banner, and update the canonical/OG URLs once the
> final hosting domain is confirmed.

## Run locally

No build step required.

```bash
git clone https://github.com/priyanshu18611/ek-villain-priyanshu.git
cd ek-villain-priyanshu
```

Open `index.html` directly in a browser, or serve the folder with any
static server, e.g.:

```bash
npx serve .
```

## Deploy on GitHub Pages

1. Push the root files and the `assets/` folder to the `main` branch.
2. Go to **Settings → Pages**.
3. Select the branch and `/ (root)`.
4. Save, then open the generated Pages URL.
